## 1. 绝对不做的功能（硬性红线）

以下能力本工具**永远不实现**，也不接受功能请求；任何模块（含未来的插件）都不得越过：

| 不做 | 说明 |
| --- | --- |
| 读取游戏进程内存 | 不调用 `ReadProcessMemory` / `OpenProcess`，不持有任何游戏进程句柄，不读取游戏存档/内存数值 |
| 注入与 Hook | 不注入 DLL，不调用 `VirtualAllocEx` / `WriteProcessMemory`，不调用 `SetWindowsHookEx` / `SetWinEventHook`，不拦截或改写游戏消息 |
| 修改游戏数据 | 不写游戏本地文件、不改内存值、不碰云端数据（除你自己在库街区上的标记进度，且必须经官方授权与官方接口） |
| 模拟键鼠输入 | 不调用 `SendInput` / `keybd_event` / `mouse_event`，不依赖 `pyautogui` / `pynput` / `keyboard` / `mouse`；无自动拾取、自动寻路、自动战斗、自动点击 |
| 绕过反作弊 / 隐蔽自身 | 不做任何规避检测的处理，不隐藏进程、不伪装窗口 |
| 采集账号密码 | 界面没有任何账号密码输入框；对 OAuth 响应做字段白名单，疑似凭据字段（`password`/`passwd`/`pwd`/`account`/`phone`/`mobile`/`sms_code`/`otp`）一律丢弃 |
| 抓取私有接口 / 绕过鉴权 | 不内置任何需要登录态才能访问的接口地址，不绕过鉴权/验证码/风控，不采集任何用户身份数据；云端只访问你（或官方文档）明确写进 `kuro_api.json` 的端点。`tools/fetch_official_map.py` 属于例外口径：它只请求**任何人匿名打开官方大地图网页时浏览器都会发的同一批公开静态文件**（见第 4 节），不涉及登录态与用户数据 |
| 上传截图或游戏数据 | 屏幕像素只在内存里比对，不上传、不落盘；上传给云端的只有「点位 id + 是否完成」（私人点位被勾选完成时，回传的也只是它的 id，坐标不出本机） |

## 2. 为什么它不属于外挂

判定外挂的关键是**是否干预游戏进程或游戏数据**。本工具：

1. 是**独立进程**的桌面窗口，与《鸣潮》没有任何进程级交互（不打开句柄、不注入、不 Hook）；
2. 数据来源是**公开地图资料**（官方/社区公开导出、你放入的公开数据包）或内置示例数据；
3. 记录的是**你本人在工具里的标记**，写在本机 JSON 文件里；
4. 识图定位与「人眼看小地图再在大地图上找位置」信息通路等价 —— 它只读取**屏幕已显示的像素**，
   不获取任何游戏内部数值，输出是带误差的估计位置；
5. 全局快捷键用的是 Windows 官方 `RegisterHotKey`：由系统把热键消息**分发给本程序**，
   不监听、不拦截、不产生其它窗口的输入（详见 `src/kumap/core/hotkeys.py`）；
6. 不产生任何输入事件，不代替玩家做任何游戏内操作。

程序内声明原文：

> 本工具是纯粹的探索参考辅助：只展示公开地图数据、记录你本人的标记进度，并通过屏幕像素识别估算当前位置。它不读取游戏内存、不注入进程、不修改游戏数据、不模拟任何键鼠操作，因此不属于外挂程序。识图定位存在误差，仅作探索参考，不保证识别结果完全准确。请遵守《鸣潮》用户协议与库街区社区规范使用本工具。

**免责原文：**

> 识图定位存在误差，本工具仅为探索参考辅助，不保证识别结果完全准确

使用建议：请自行确认《鸣潮》用户协议与库街区社区规范对「外部参考工具/截图识别」的现行条款；
若官方明确禁止某类辅助行为，请停止使用对应功能（识图开关、云端同步都可以单独关闭）。
本工具不因使用而产生的任何账号风险由使用者自行承担。

## 3. 账号与凭据处理

| 环节 | 实现 |
| --- | --- |
| 登录入口 | 只跳转**库街区官方授权页**（系统浏览器），手机号验证码/扫码全部在官方页面完成，本工具不经手、也看不到凭据 |
| 协议 | OAuth2 授权码 + PKCE（S256）+ `state` 随机校验；回调只监听本机 `127.0.0.1:8756`，`state` 校验通过后立即关闭监听，等待上限 180 秒 |
| 授权范围 | 默认仅 `map.markers.read`、`map.markers.write`（读取与回写你自己的大地图标记） |
| 存储 | 令牌经 **Windows DPAPI**（`crypt32!CryptProtectData`，绑定当前 Windows 用户 + 附加应用熵）加密后写入 `<数据目录>\credentials.bin`，文件权限按 0600 设置；密文换机器或换 Windows 用户无法解密 |
| 明文 | 任何情况下不落明文：解密失败直接视为未登录，不做明文回退；`config.json` 的 `account` 段只有 `mode`、`uid_masked`（形如 `12****89`）与 `nickname`，不含任何令牌 |
| 退出登录 | `AuthManager.logout()` → `SecureStore.clear()`，立即删除 `credentials.bin`；本地进度文件保留 |
| 非 Windows 开发环境 | 回退为 PBKDF2 派生密钥 + Fernet（`credentials.key`，0600），仅用于调试，不建议这样长期使用 |
| 第三方 | 不接任何第三方登录/统计/上报服务；网络请求只允许 `http`/`https`、超时 12 秒、响应体上限 12 MB，且只发往 `kuro_api.json` 里配置的官方端点 |
| 字段过滤 | token 响应只保留 `access_token`/`refresh_token`/`token_type`/`expires_in`/`scope`，其它字段（含疑似账号密码字段）丢弃 |

**当前诚实状态：** 库街区**尚未公开**有文档的第三方 OAuth 授权端点与大地图读取接口。因此在配置官方端点之前，
云端拉取/回传按钮会提示「未配置」，程序整体运行在**本地模式**。本工具不自带私有接口，也不做逆向抓取。

## 4. 数据口径

1. **公开数据 / 示例数据 / 你自己的标记** 三类，程序会区分对待：
   - 内置点位与路线：`source = "sample"`，由 `tools/gen_sample_data.py` 按固定随机种子生成，**不是**官方或库街区真实坐标；
     内置底图 `resources/map/world_map.png` 是 `tools/gen_placeholder_map.py` 自绘的**占位示例图**，不含任何官方美术资源。
   - 导入数据：`source = "imported"`，只应使用官方或社区**公开导出**的数据包；转载路线请保留 `author` 出处。
   - 你的标记/备注/私人点位：只写在你本机的 `markers.json` / `private_points.json` / `favorites.json`。
2. 程序运行时**不联网抓取任何官方数据**，也不提供任何需要登录态的抓取脚本；对外请勿把示例坐标宣称为官方或库街区真实点位。
3. 关于 `tools/fetch_official_map.py`（官方大地图公开资源本地化，**源码仓库里的开发脚本，不打进 exe**）：
   - 只做三类请求：① 一次匿名 `POST api.kurobbs.com/map/core/config/getMapResource` 取「地图资源 id」（空 body、无任何凭据）；
     ② `web-static.kurobbs.com` 下的公开静态 JSON（点位/目录/国家/瓦片元数据）；③ 同域下的公开图片瓦片。
     域名与路径全部是网页公开可见的请求，脚本不解析加密返回、不带 Cookie/Token、不访问任何用户数据接口。
   - 硬性约束由测试守着：`tests/test_official_map.py::test_fetcher_only_touches_public_official_hosts`
     会扫描脚本源码，断言域名白名单、禁用的登录/验证码/凭据/后台关键字、以及依赖面（只有标准库 + `PySide6.QtGui` 拼图）。
   - 使用口径：**低频一次性**（默认串行 + 0.25s 间隔 + 本地缓存，请不要调小 `--delay`、不要挂定时任务反复抓）；
     抓下来的图片与数据版权归库洛游戏，仅个人学习研究，**不得二次分发、不得商用、不得打包进任何安装包**。
   - 它产出的是「显示用的底图 + 公开点位」，与本工具的识图定位互为独立功能：脚本不参与运行时流程，运行期依旧零抓取。
4. 《鸣潮》、库街区相关名称、素材/声骸等名词及地图美术版权归**广州库洛科技有限公司**所有，本项目仅作知识性引用。
5. 二次分发提醒：社区公开数据包通常有各自的许可条款，请勿把抓取/复制来的原始点位库对外再分发；
   分享工具时只分享程序与你自己整理的说明。

## 5. 识图定位的像素处理说明

| 事项 | 事实 |
| --- | --- |
| 取图方式 | `mss` 截取**主显示器整屏**一帧到内存（`core/recognizer.py` 的 `_capture()`；`VisionConfig.monitor_index` 恒为默认值 0 = 主屏，界面与配置文件都不提供切屏入口） |
| 用途 | 裁剪游戏小地图区域 → 灰度/去黑圈/CLAHE → ORB 特征 → 与大地图多尺度特征索引匹配 → RANSAC 仿射 → 归一化坐标、朝向、比例尺 |
| 是否落盘 | **否**。代码里没有任何 `imwrite` / 截图保存路径；截图帧是函数内临时数组，函数返回后即可被回收 |
| 是否上传 | **否**。识图全程本地计算；上传给云端的内容只有点位完成状态，且云端本身默认未启用 |
| 是否进日志 | 只写统计量（耗时、内点数、good 匹配数、置信度、失败原因码），不写像素、不写截图 |
| 注意 | 截屏会包含屏幕上任何其他可见内容，请勿在含敏感信息的界面上开启识图；不需要时按 `Ctrl+Alt+V` 关闭 |
| 精度 | 存在误差，可能失败或偏移；连续失败会自动降频并提示改用「手动标记我的位置」 |

## 6. 自查清单（发布前建议逐条跑一遍）

Windows（PowerShell）：

```powershell
Get-ChildItem -Recurse -Filter *.py src\kumap |
  Select-String -Pattern "ReadProcessMemory|VirtualAllocEx|WriteProcessMemory|SetWindowsHookEx|SetWinEventHook|SendInput|keybd_event|mouse_event|pyautogui|pynput"
```

Linux / macOS（bash，或 Windows 上装了 ripgrep 时 `rg -n "..." src`）：

```bash
grep -rnE "ReadProcessMemory|VirtualAllocEx|WriteProcessMemory|SetWindowsHookEx|SetWinEventHook|SendInput|keybd_event|mouse_event|pyautogui|pynput" src/
```

**期望结果（本仓库 v0.1.0 的实测）：** 以上关键字**只出现在** `src/kumap/core/recognizer.py` 顶部的合规约束注释里，
没有任何可执行调用。

同样的检查已经固化进测试：`tests/test_core_platform.py` 会逐个解析 `src/kumap/**/*.py` 的 AST，
断言没有禁区 API 调用（`ctypes.windll.*` 只允许热键与 DPAPI 那几个白名单符号）、网络与回环监听只出现在
`core/provider.py` 和 `core/auth.py`、没有输入模拟依赖、识图模块的依赖面只有 `numpy`/`cv2`/`mss`/标准库/`PySide6`，
并且 `COMPLIANCE_STATEMENT` 能正常导入且包含关键承诺（`test_no_forbidden_api_usage` /
`test_no_input_simulation_imports` / `test_recognizer_only_uses_screen_pixels` / `test_compliance_statement_is_shipped`）。
在项目根跑 `python -m pytest tests -q` 即可一并覆盖。

配套检查：

- [x] `ctypes` 仅两处使用：`core/secure_store.py` 调 `crypt32!CryptProtectData/CryptUnprotectData` + `kernel32!LocalFree`（DPAPI）；
      `core/hotkeys.py` 调 `user32!RegisterHotKey/UnregisterHotKey`（官方热键 API，非 Hook）。
- [x] 无 `socket` / 无第三方 `requests`：网络只用 `urllib`（`core/provider.py`）与 Qt 的 `QTcpServer`
      （`core/auth.py` 回环监听），且只允许 `http`/`https`。
- [x] 识图链路无写文件：`src/` 内不存在 `imwrite`（只有 `tests/test_recognizer.py` 为了造测试图片才用 `cv2.imwrite`）。
- [x] 无输入模拟：仓库不依赖 `pyautogui` / `pynput` / `keyboard` / `mouse`，`requirements*.txt` 中也不含它们。
- [x] 界面搜不到密码框：账号流程只有「打开官方授权页面」按钮与说明页（`ui/login_dialog.py`），
      没有 `QLineEdit` 采集密码、也没有任何密码字段写盘。
- [x] 凭据文件只可能是 `credentials.bin`（DPAPI 密文）与 `credentials.key`（非 Windows 开发回退），
      两者都在 `.gitignore` 里，且都写在**用户数据目录**而非程序目录。
- [x] 首启必弹合规确认，不同意直接退出（`main.py` 的 `terms_accepted` 分支）。
- [x] 可选依赖缺失时只降级不报错：`opencv-python` / `numpy` / `mss` 缺失 → 识图自动禁用并提示手动定位。
- [x] 抓取脚本域名白名单：只有 `web-static.kurobbs.com` / `api.kurobbs.com` / `www.kurobbs.com`（Referer），
      且不出现登录、验证码、凭据、后台写接口关键字（`tests/test_official_map.py` 静态扫描）。
- [x] 运行期不联网抓官方数据：`src/kumap/**/*.py` 里没有任何 `mcmap/`、瓦片 URL 或 `web-static` 字符串
      （只有 `resources/README_data.md` 以知识性引用列出大地图主页链接），官方数据包只在用户主动跑脚本时产生，
      程序运行只读本地 `import/`。

## 7. 一句话总结

这个工具做的事，和一个「把公开大地图开在副屏、自己在上面打勾、必要时看一眼小地图猜位置」的玩家没有区别：
它只展示公开地图数据、只记录你本人的标记进度、只读取屏幕像素来估算位置，不碰游戏本身。

> 识图定位存在误差，本工具仅为探索参考辅助，不保证识别结果完全准确
