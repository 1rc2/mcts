# 鸣潮 · 库街区大地图探索助手

Windows 桌面端探索辅助工具。轻量悬浮窗、窗口置顶、可调透明度，尽量少遮挡游戏画面；支持大地图点位分层、玩家路线导航、本地标记、屏幕识图定位。

> **数据来源**
> 内置底图与点位来自库街区大地图**公开静态资源**（`web-static.kurobbs.com`），已由本工具**离线打包**，运行时无需联网、无需登录、不携带任何 Cookie/Token。
> 打包脚本见 `scripts/import-official-map.py`，可随时重新拉取公开数据。点位共约 1.9 万个（煌珑），含采集物、敌人、奇藏箱、探索、副本、NPC 等分类。

> **合规声明**
> 本工具**不读取游戏进程内存、不注入进程、不修改游戏数据**，**无自动点击、无自动寻路、无任何游戏操作模拟**。
> 所有点位/路线来自库街区公开地图与公开静态资源；识图功能仅分析屏幕截图像素。
> 本工具不属于外挂程序。账号登录全程在库街区官方授权页完成，工具不接触、不保存账号密码。
>
> **误差声明**
> 识图定位基于屏幕像素匹配，**存在误差**，会受到分辨率、缩放、UI 透明度、天气/光照、小地图旋转等因素影响；识别结果**仅作探索参考**，不保证完全准确。

## 功能

- **地图**：高清大地图缩放/平移；宝箱、锚点、材料、声骸、敌人、解谜、任务、NPC 分层开关；一键全显/全隐；差异化图标。
- **路线**：加载玩家分享路线并在地图绘制；上一个/下一个目标切换、自动标记当前目标、完成当前点自动推进；收藏与随时切换。
- **标记**：手动标记完成（变暗打勾）、一键隐藏已完成、新增私人点位与备注、悬浮查看详情/掉落/备注、关键词搜索。
- **识图定位**：本地截屏识别游戏小地图并更新当前位置；频率、显示器、框选区域、视野范围、置信度均可调；连续失败自动切换为手动点击定位。
- **窗口**：置顶、透明度、锁定尺寸、最小化到托盘、深/浅主题、全局快捷键。
- **账号与进度**：官方授权页登录（无账号也可用全部本地功能）；绑定成功后自动拉取已完成点位，之后每次启动静默同步一次；也可手动拉取/一键回传；未配置官方接口时用进度文件互通，本地标记仅存本机。

## 运行与打包

环境：Windows 10/11 x64；开发需 Node.js 20+。

```bash
npm install
npm start          # 开发运行
npm run dev        # 开发运行（--dev）
npm test           # 算法与数据校验测试
npm run pack:dir   # 生成免安装目录 release/win-unpacked
npm run dist:win   # 生成 NSIS 安装包与便携版到 release/
```

仓库已提供 Linux 下交叉构建的便携版：`release/WuwaMapCompanion-1.0.0-portable.exe`（单文件，双击运行）。如需带自定义图标的正式安装包，请在 Windows 上执行 `npm run dist:win`。

## 首次使用

1. 启动后默认显示离线打包的**煌珑**地图与官方公开点位，无需联网。若想换成自己的高清地图，可在「设置 → 地图数据 → 导入高清地图」选择图片；点位按归一化坐标自动贴合。
2. 在「设置 → 识图定位」选择游戏所在显示器，点击「框选小地图」，在游戏画面上拖拽框选**完整的小地图圆盘**。
3. 打开游戏小地图后开启识图。若定位不准，优先调整「视野范围」（小地图圆盘在游戏大图上对应的像素直径，默认 720），再微调「置信度阈值」。
4. 识别连续失败 3 次会自动停用识图，并进入手动定位模式：直接在地图上点击你所在的位置即可。
5. 无账号也可使用全部地图、路线、标记功能；进度保存在本机。

## 识图校准建议

- 游戏使用**窗口化或无边框窗口**；全屏独占模式下悬浮窗可能无法置顶显示。
- 小地图 UI 缩放、游戏分辨率变化后需重新框选。
- 「视野范围」过小/过大都会降低匹配分数：从默认值开始，每次调整 40–80，观察底部识图状态中的匹配分数，稳定高于阈值即可。
- 识别间隔默认 1500ms；越低越耗资源，建议 800–2000ms。

## 数据格式

点位 JSON（也支持直接是数组）：

```json
{
  "markers": [
    {
      "id": "chest-001",
      "type": "chest",
      "u": 0.42,
      "v": 0.31,
      "region": "荒石高地",
      "name": "精致宝箱",
      "drops": "星声 ×5",
      "note": "山顶背面"
    }
  ]
}
```

`type` 取值：`chest | anchor | material | echo | enemy | puzzle | quest | npc | custom`；`u`、`v` 为 0–1 的归一化坐标（相对地图宽高）。

路线 JSON：

```json
{
  "routes": [
    {
      "id": "route-demo",
      "name": "玩家分享路线",
      "author": "示例玩家",
      "desc": "可选说明",
      "points": [
        { "u": 0.42, "v": 0.31, "markerId": "chest-001", "label": "精致宝箱" },
        { "u": 0.45, "v": 0.35 }
      ]
    }
  ]
}
```

在「地图 → 导入路线」加载后即可收藏、切换。进度可用「账号 → 导出/导入进度文件」在设备间手动互通。

## 账号与云端同步说明

- 登录通过系统浏览器打开库街区**官方授权页**完成，工具只接收授权码并交换令牌；**不抓取、不记录账号密码**。
- 令牌使用 Electron `safeStorage`（Windows DPAPI）加密后仅存本机；退出登录立即清除。
- 云端拉取/回传需要库街区官方开放平台分配的接口与 `client_id`、`redirect_uri`。在「账号 → 官方授权接口配置（高级）」填写后启用；所有请求由本机直接发往官方地址，不经过任何第三方服务器。
- 未配置官方接口时，工具明确处于**本地模式**，只提供进度文件导入/导出，不伪造云端同步。

## 常见问题

- **窗口没有盖在全屏游戏上**：请将游戏改为窗口化/无边框；全屏独占会抢占顶层显示。
- **识图一直失败**：检查是否框选完整小地图圆盘、显示器是否选对、游戏分辨率是否变化；也可直接手动点击定位。
- **快捷键无效**：可能被系统或其他软件占用，设置页会提示注册失败，换一个组合即可。
- **关闭窗口后程序仍在**：点击标题栏关闭会最小化到托盘，从托盘菜单可重新显示或退出。
- **数据位置**：设置页「打开数据目录」可查看 `settings.json`、`progress.json`、导入的地图图片与加密凭证文件。

## 目录结构

```
main/           主进程（窗口、托盘、快捷键、截屏、账号、持久化）
renderer/       界面与地图渲染、识图控制器
renderer/js/    地图视图、匹配算法、Worker、UI 主控
data/           地图元数据、官方公开点位与示例路线
assets/maps/    离线拼接的煌珑底图
scripts/        公开数据导入脚本（Python + Pillow）
test/           匹配算法与数据校验测试
```

底图与点位来自库街区大地图公开静态资源，由本工具离线打包，仅作本地展示与个人探索参考；版权归原权利方所有。点位坐标由官方世界坐标换算为归一化坐标，个别室内/分层点位可能落在异常位置，可通过类型筛选隐藏。
